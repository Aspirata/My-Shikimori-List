# My Shikimori List

[![License](https://img.shields.io/badge/License-MIT-orange.svg)](./LICENSE)

**Красивый и удобный вывод** списка аниме с **[Shikimori.one](https://shikimori.one/)**

Сайт получает данные через официальное API и формирует аккуратный, читабельный список с русскими статусами, тегами и возможностью копирования в буфер обмена.

## Для чего это сделано и где может пригодиться ?
Я сделал этот сайт, чтобы получить свой список аниме в чистом, но полном, текстовом виде и закинуть его в любую LLM — для рекомендаций «что посмотреть дальше»  
Ещё этот сайт полезен, если вы хотите где-то опубликовать свой список аниме или отправить его другу lol

> [!WARNING]
> РКН заблокировал Shikimori.one и некоторые из зеркал, поэтому вам нужен vpn или любой другой способ обхода, чтобы получить свой список
