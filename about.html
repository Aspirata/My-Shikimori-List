О сайте My Shikimori List

На главную

Что это такое и зачем

My Shikimori List — небольшой инструмент для просмотра аниме-листа с Shikimori в удобном текстовом формате. Просто введите никнейм — и получите список в нескольких вариантах представления: краткий, обычный или подробный.

Полезно, когда хочется поделиться своим списком в чате, скопировать для заметок или получить рекомендации что посмотреть.

Разработка

Сайт написан на HTML / CSS / JavaScript, без фреймворков и зависимостей, данные получаются напрямую из публичного API Shikimori.

✦

Бо́льшая часть кода написана с помощью Claude Sonnet 4.6 от Anthropic
